# Gin Framework Starter Project

This is a ready-to-use project based on the Gin framework, encapsulating various components to help you quickly start building web applications.

## Features

- **Custom Logging**: Logs are formatted in JSON with detailed information including client IP, timestamp, method, path, latency, protocol, status code, body size, referer, user agent, and error message.
- **Basic Authentication**: Example of using Gin's built-in basic authentication middleware.
- **RESTful API**: Includes examples of GET and POST requests.
- **Ping Endpoint**: A simple `/ping` endpoint to test the server's availability.
